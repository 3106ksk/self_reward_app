# MVP要件実装用プロンプト

`/Users/310tea/Documents/Project/self_reward_app/docs/mvp_implementation_design.md` の設計書を唯一の仕様として、現在のRailsアプリへMVP要件を実装してください。

## 前提

- 対象アプリ: `/Users/310tea/Documents/Project/self_reward_app`
- 設計書の内容を最優先する
- 設計書と既存コードが矛盾する場合は、既存コードを読んだうえで最小変更で設計書に合わせる
- 設計書にない仕様を勝手に追加しない
- 既存のユーザーセッション機能は壊さない
- 既存の`User has_one :goal` / `Goal belongs_to :user`構造は維持する
- 他ユーザーのGoal / Subgoal / Quest / SmallRewardを操作できないようにする
- UI文言は、日次Todo管理アプリに見えないようにする

## 特に守ること

- `TodoItem`は`Quest`へ再定義する
- `todo_items`は`quests`へ変更する
- サブゴール配下に置くものは、毎日のTodoではなく「サブゴール達成に必要なクエスト」として扱う
- 「今日のTodo」「今日やったこと」「今日の一歩」「完了タスク」など、日次Todoを連想させる文言を実サービス画面から削除する
- サブゴールとクエストの`position`入力欄はフォームから削除する
- `position`は内部用に残し、作成時はController側で末尾へ自動追加する
- サブゴールとクエストの並び替えはMVPでは実装しない
- 上へ/下へボタン、ドラッグ&ドロップはMVP後の拡張候補として扱い、今回実装しない
- 小さなご褒美はGoal配下の「ご褒美リスト」として作成する
- 小さなご褒美フォームの入力項目は`ご褒美名`だけにする
- 小さなご褒美に`メモ`、`表示順`、`有効/無効`は実装しない
- クエストをクリアしたら、小さなご褒美リストから1つ選んでQuestに紐づける
- 小さなご褒美はゴールドや交換所ではなく、Todoリストのご褒美版のような軽い実装にする
- サブゴール内の全Questがクリアされたら、サブゴール達成として大きなご褒美を獲得できる
- `subgoals.reward_*`カラムはMVPではDB名を無理に変えなくてよい。画面文言では「大きなご褒美」として扱う
- ゴールド、学習時間記録、連続日数、ランキング、SNS共有、複数Goal対応は実装しない
- `posts` scaffoldはMVP対象外。主要機能が安定した後に削除する
- `prototype/*`は開発用として残してよいが、本番MVP導線やテスト要件に含めない

## 実装手順

1. まず設計書と現在のコードを読んで、実装計画とTODOリストを作成する
2. TODO単位で実装する
3. 各変更後に影響範囲を確認する
4. テストを追加・更新する
5. テストを実行する
6. Browser Useで主要画面を確認する
7. 不具合があれば修正し、再度テスト・画面確認する

## オーケストレーション

あなたはオーケストレーターとしてふるまってください。

実装はTODO項目単位でworkerを起動して作業させてください。  
workerの推論レベルは`low`にしてください。

各workerには以下を必ず伝えてください。

- 担当するファイル範囲
- 他のworkerも同じコードベースで作業しているため、他者の変更を戻さないこと
- 設計書を必ず参照すること
- 上記の「特に守ること」を破らないこと
- 設計書にない仕様を追加しないこと

workerの成果物はあなたが確認してください。  
基準を満たしていない場合は、同じworkerに修正依頼を出してください。  
全TODOが完了するまでPDCAサイクルを回してください。

## 確認項目

最低限、以下を確認してください。

- ユーザー登録できる
- ログインできる
- ログアウトできる
- 未ログイン時に保護ページへアクセスするとログイン画面へリダイレクトされる
- ログイン後に自分専用のGoalが1つ作成される
- 価値観を設定・更新できる
- 長期ゴールを設定・更新できる
- サブゴールを作成・編集・削除できる
- サブゴールフォームに「順番」入力が表示されない
- クエストを作成・編集できる
- クエストフォームに「順番」入力が表示されない
- クエストを作成すると対象サブゴール内の末尾に追加される
- 実サービス画面に「Todo」「今日のTodo」「今日やったこと」「今日の一歩」「完了タスク」が表示されない
- 小さなご褒美を作成・編集できる
- 小さなご褒美フォームの入力項目はご褒美名だけ
- 作成した小さなご褒美がGoal配下のリストに表示される
- クエストクリア時に小さなご褒美リストから1つ選べる
- クエストクリア時に選んだSmallRewardがQuestに紐づく
- クエスト未クリアに戻すとSmallReward選択も解除される
- 全Questクリア前はサブゴールの大きなご褒美を獲得できない
- 全Questクリア後はサブゴールの大きなご褒美を獲得できる
- 他ユーザーのGoal / Subgoal / Quest / SmallRewardを操作できない
- ゴールド、学習時間記録、並び替え、連続日数、ランキングが追加されていない
- 主要画面をBrowser Useで確認済み
- テストが通る
