# ミチシルベ 使い方説明書

完璧主義で考えすぎてしまい、学習や挑戦を続ける中で「まだ足りない」と焦ったり、休むことに罪悪感を持つことがありました。
一方で、小さな達成をちゃんと認めたり、ご褒美で自分を労ったりすると、前向きに続けられる実感もありました。
ミチシルベは、今日の行動と未来の目標をつなぎ、頑張った分だけ安心して進み、休めるようにするためのロードマップアプリです。

ミチシルベは、長期的な学習や挑戦を「価値観」「長期ゴール」「サブゴール」「クエスト」「ご褒美」に分けて、一枚のマップで管理するサービスです。

毎日の小さな行動が、どの目標につながっているのかを見えるようにして、続ける不安や焦りを減らすことを目的にしています。

## 全体の流れ

初めて使う場合は、トップページから「アカウントを作成」を押して登録します。すでにアカウントがある場合は「ログイン」します。登録またはログインが終わると、マップ画面に移動します。

使い方の基本は、次の順番です。

1. 価値観を設定する
2. 長期ゴールを設定する
3. サブゴールを設定する
4. クエストを設定する
5. クエスト達成時に選ぶ「小さなご褒美」を用意する
6. クエストをクリアして、小さなご褒美を選ぶ
7. サブゴール内のクエストをすべてクリアして、「大きなご褒美」を獲得する

マップでは、価値観が出発点、長期ゴールが目的地、サブゴールが途中の通過点、クエストが今日から進める具体的な行動として表示されます。

## 1. 価値観を設定する

価値観は、「なぜこのゴールを目指したいのか」「何を大切にしながら進みたいのか」を書く場所です。

## 2. 長期ゴールを設定する

長期ゴールは、最終的にたどり着きたい目的地です。大きすぎる夢ではなく、「達成できたかどうかが自分で判断できる状態」にすると使いやすくなります。

例:

- 3か月後に小さなRailsアプリを公開する
- 英語で10分間、自分の考えを話せるようになる
- 基本情報技術者試験に合格する

設定方法:

1. 「長期ゴール設定」を開く
2. 「長期ゴール」に目的地を書く
3. 「長期ゴールの説明、理想状態」に、達成したと判断できる状態を書く
4. 「長期ゴールを更新」を押す

長期ゴールは、マップのゴール地点として表示されます。

## 3. サブゴールを設定する

サブゴールは、長期ゴールまでの途中に置く通過点です。長期ゴールをいきなり目指すのではなく、いくつかの段階に分けることで、次に何をすればよいかが分かりやすくなります。

例:

- ユーザー登録とログイン機能を完成させる
- 毎日30分の学習習慣を2週間続ける
- 試験範囲の基礎問題を一周する

設定方法:

1. 「サブゴール設定」を開く
2. 「サブゴール名」に通過点の名前を書く
3. 「説明、メモ」に、到達したい状態や補足を書く
4. 「大きなご褒美」に、このサブゴールを達成したら受け取りたいご褒美を書く
5. 「大きなご褒美の説明、メモ」に、いつ・どんな形で受け取るかを書く
6. 「サブゴールを追加」を押す

サブゴールは最大5つまで追加できます。追加したサブゴールはマップ上の通過点として表示されます。

## 4. クエストを設定する

クエストは、サブゴールを達成するための具体的な行動です。「今日やること」「短い時間で終わる作業」くらいまで小さくすると、クリアしやすくなります。

例:

- ユーザー登録画面を作る
- Railsのバリデーションについて30分調べる
- 英単語を20個復習する
- 過去問を10問解く

設定方法:

1. 「クエスト設定」を開く
2. 「クエスト名」に具体的な行動を書く
3. 「説明、メモ」に、クリア条件や進め方を書く
4. 「関係するサブゴール選択」で、どのサブゴールに紐づけるか選ぶ
5. 「クエストを追加」を押す

追加したクエストは、選んだサブゴールの下に表示されます。未クリアのクエストとクリア済みのクエストは、マップ上で分かれて表示されます。

## 5. クエスト達成時のご褒美を選ぶ準備をする

クエストをクリアするときには、「小さなご褒美」を選べます。小さなご褒美は、毎日の行動を続けるための軽い報酬です。

おすすめの小さなご褒美:

- 好きな飲み物を飲む
- 10分だけ動画を見る
- 散歩する
- 好きな音楽を1曲聴く
- 早めに休憩する

設定方法:

1. 「小さなご褒美設定」を開く
2. 「ご褒美名」に、クエスト達成後に受け取りたいご褒美を書く
3. 「小さなご褒美を追加」を押す

小さなご褒美は複数登録できます。クエストをクリアするときに、その中から1つ選びます。

クエストをクリアするには、小さなご褒美が少なくとも1つ必要です。先に小さなご褒美を登録してから、クエストをクリアしてください。

## 6. クエストをクリアして小さなご褒美を選ぶ

クエストが終わったら、マップ上のクエストを開いてクリアします。

手順:

1. マップ上の未クリアクエストを選ぶ
2. クエスト内容を確認する
3. 「小さなご褒美」から受け取りたいものを選ぶ
4. 「クリアする」を押す

クリアしたクエストは「クリア済みクエスト」として表示されます。選んだ小さなご褒美も、そのクエストに記録されます。

間違えてクリアした場合は、クエストを開いて「未クリアに戻す」を押すと戻せます。

## 7. サブゴール達成後に大きなご褒美を獲得する

サブゴールに紐づくクエストをすべてクリアすると、そのサブゴールは達成状態になります。達成すると、サブゴールに設定していた「大きなご褒美」を獲得できます。

手順:

1. サブゴール内のクエストをすべてクリアする
2. マップ上のご褒美ポイントが「獲得可」になる
3. サブゴール、またはご褒美ポイントを選ぶ
4. 「大きなご褒美を獲得する」を押す

獲得後は、ご褒美ポイントが「獲得済み」として表示されます。

大きなご褒美は、サブゴールごとに設定します。小さなご褒美より少し特別なものにすると、区切りとして分かりやすくなります。

例:

- 欲しかった本を買う
- カフェでゆっくり作業する
- 半日休む
- 行きたかった場所に行く
- 新しい教材やツールを購入する

## ご褒美の選び方

ご褒美は、行動を続けるための仕組みです。高価なものや特別なものだけでなく、「達成した自分をちゃんと認める時間」として選ぶのがおすすめです。

小さなご褒美は、クエスト1つに対してすぐ受け取れるものにします。

例:

- 5分から15分で終わる休憩
- その日のうちに受け取れる楽しみ
- 次のクエストの邪魔にならないもの

大きなご褒美は、サブゴール達成後に受け取る少し特別なものにします。

例:

- 数日から数週間の頑張りに見合うもの
- 達成の区切りを感じられるもの
- 次のサブゴールに進む気持ちを整えられるもの

## 迷ったときの入力例

Webアプリを作りたい場合:

- 価値観: 自分のアイデアを形にして、人に使ってもらえるようになりたい
- 長期ゴール: 3か月後に小さなRailsアプリを公開する
- サブゴール: ユーザー登録とログイン機能を完成させる
- クエスト: ユーザー登録画面を作る
- 小さなご褒美: 好きなコーヒーを飲む
- 大きなご褒美: 新しい技術書を1冊買う

資格勉強を進めたい場合:

- 価値観: 将来の選択肢を増やすために、基礎力をつけたい
- 長期ゴール: 基本情報技術者試験に合格する
- サブゴール: 午前問題の基礎分野を一周する
- クエスト: 過去問を10問解く
- 小さなご褒美: 10分だけ動画を見る
- 大きなご褒美: 試験勉強用の文房具を買う

## 使うときのコツ

- 最初から完璧な計画にしなくて大丈夫です。
- 価値観は、途中で変わったら書き直してください。
- 長期ゴールは、達成した状態が分かる言葉にします。
- サブゴールは、長期ゴールまでの通過点として設定します。
- クエストは、小さく具体的にします。
- 小さなご褒美は、すぐ受け取れるものにします。
- 大きなご褒美は、サブゴール達成の区切りになるものにします。

ミチシルベでは、クエストを1つずつクリアすることで、長期ゴールまでの道のりが少しずつ進んでいきます。
